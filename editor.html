How do I get the token?
  1. GitHub-এ লগইন করে ছবিতে ট্যাপ করো → Settings → একদম নিচে Developer settings।
  2. Personal access tokens → Fine-grained tokens → Generate new token।
  3. Name: Site editor। Expiration: ১ বছর।
  4. Repository access: Only select repositories → তোমার সাইটের repo বেছে নাও।
  5. Permissions → Repository permissions → Contents → Read and write।
  6. Generate token চাপো, যে কোডটা আসবে সেটা কপি করে এখানে paste করো। পেজ ছেড়ে দিলে আর দেখা যাবে না।
